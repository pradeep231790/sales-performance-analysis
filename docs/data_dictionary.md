# Data Dictionary

## Employees

| Column | Type | Description |
|---|---|---|
| employee_id | INT | Unique employee identifier |
| employee_name | VARCHAR | Employee name |
| department | VARCHAR | Employee department |

## Products

| Column | Type | Description |
|---|---|---|
| product_id | INT | Unique product identifier |
| product_name | VARCHAR | Name of product |
| category | VARCHAR | Product category |

## Sales

| Column | Type | Description |
|---|---|---|
| order_id | INT | Unique sales order |
| employee_id | INT | Employee responsible for sale |
| product_id | INT | Product sold |
| sales_value | DECIMAL | Revenue generated by order |
